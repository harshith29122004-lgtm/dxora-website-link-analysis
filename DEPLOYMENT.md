# Public deployment

This repository includes a Render Blueprint in `render.yaml` for the FastAPI service.

## Before deploying

1. Confirm that you control the hosting account and create a new Blueprint from this public GitHub repository.
2. In Render, provide `LLM_API_KEY` as a secret. Do not commit the key to GitHub or put it in this file.
3. Confirm the selected model name and provider support the OpenAI-compatible Chat Completions API used by this application. The default values are examples and may need to be changed to match the API account you own.
4. Review the outbound network security note below before exposing this service publicly.

## Expected public endpoints

After Render finishes deploying, use the service's assigned HTTPS hostname:

- Health: `https://<your-render-host>/health`
- API docs: `https://<your-render-host>/docs`
- Analysis: `POST https://<your-render-host>/link-analysis`

Example request:

```bash
curl -X POST "https://<your-render-host>/link-analysis" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com"}'
```

A successful health check only confirms that the API process is running. Verify the analysis endpoint with a valid provider key before sharing the live demo.

## Important production security requirement

The application validates submitted URLs and checks DNS results, but its own README documents DNS rebinding as a remaining edge case because the HTTP client performs its own hostname resolution. A public deployment must enforce outbound network restrictions at the hosting/network layer (block loopback, private, link-local, reserved, and cloud-metadata ranges for IPv4 and IPv6, including after DNS resolution and redirects) or add a hardened egress proxy. Do not expose the public analysis endpoint until this control has been implemented and verified.

## Notes

- The Render service URL is generated by Render; it cannot be known before the service is created.
- Free-tier availability, sleep behaviour, and current limits are controlled by Render and may change.
- No API key is stored in this repository.
